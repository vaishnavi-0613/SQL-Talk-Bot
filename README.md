\# SQL Talk Bot 🗄️



Talk to any data file (SQLite, Excel, CSV, JSON, Parquet) in plain English.

Upload a file, ask questions, and the bot generates + runs SQL against it,

powered by Groq's Llama models via LangChain.



\## Setup

1\. `pip install -r requirements.txt`

2\. Create a `.env` file with `GROQ\_API\_KEY=your\_key\_here` (get one free at console.groq.com/keys)

3\. `streamlit run app.py`
